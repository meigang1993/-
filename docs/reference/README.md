# docs/reference · 权威快照索引

权威源始终是 `src/original/` 与 `publish/`；本目录文件不参与构建、不被 bundle 引用。

## 使用约定

- **改游戏数值**：改 `src/original/`，重建 bundle，再重生成这里的快照；不要直接改本目录的清单当作实现。
- **设计稿 vs 实现**：`docs/05`、`docs/12`、`docs/废墟沙城怪物设计最新版本.txt` 为交接/设计资料；
  2026-11-24 已把三份文档里废墟沙城 9 只的**基础属性**同步到源码当前值，但设计稿仍保留早期副本结构、
  等级上限等设定（差异见 `docs/开发日记.md` 补记条目）。有冲突时以本目录清单与 `src/original/` 为准。
- **更新公告**：往期条目按既有「历史原文保留」口径不动，新条目写入 `src/original/update-notice-recent.js` 首期。

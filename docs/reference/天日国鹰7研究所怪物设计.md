## 一、随机池复用结论

「普通战斗节点随机抽取 1 至 4 个普通怪物，可以出现 4 个相同怪物，以 ABCD 编号区分」
**不需要新写机制**：`dungeon-enemies.js` 里四个副本共用的既有范式已经完全实现。

| 既有函数 | 作用 |
| --- | --- |
| `rand(1, 4, state)` | 普通节点抽 1~4 只 |
| `pickRepeatable(pool, picked, state)` | 同一 id 最多抽 4 次，允许 4 只相同怪 |
| `withLabels(list)` | 重复 id 按出现顺序标 A / B / C / D，只出现一次不标 |
| `scaleEnemy(base, diff, type)` | 五档难度统一缩放 |

本次只新增一条 `tenriEnemies` 分支调用这套函数。因为精英与首领怪尚未设计，
三型节点（normal / elite / boss）都从 4 只普通怪里随机，按节点类型吃难度倍率，
**不会混入其它副本的怪物 id**。入口仍按既有占位口径 `devLocked` 显示「未开发完成」。

## 三、技能实现口径

- **不可挡突袭**：只认实体单体【杀】；比较出牌者与目标角色**手牌中的【杀】牌数**，
  多出 n 张时该杀不可响应、伤害 ×(1+n)。挂 `beforeKillTargeted` + `modifyAttackAmount`。
- **守护后方**：其他我方角色成为实体单体【杀】目标、且该角色没有此技能时，
  目标在 `useCard` 入口转移给防爆队，日志/飞行/响应/伤害/状态全部按新目标结算；
  多个防爆队取第一个未被时停的。
- **极速射线**：全体类实体牌（`isEntityCard && (isGroupTargetCard || demonInvasion)`）
  不可响应、伤害翻倍。标记挂在 `beforeCardPlayed`（覆盖绕过攻击流程的实体战术牌），
  翻倍挂在统一命中出口 `modifyIncomingDamage`，避免重复乘 2。
- **快速复生**：死亡后进入待复活，于自己下个回合开始满血复活；
  「其他我方角色存活」在死亡瞬间与复活瞬间各判一次，避免队友全灭时战斗挂起。
  复用全项目 `pendingRevival` 链（死亡判定 / 弃牌 / 胜负 / 回合流转均认它），
  与不死食尸鬼共用免死统一入口，但复活逻辑先执行且不互相抢标记。

### 2026-11-25 公开描述修订

四段技能文案按用户新稿逐字修正（权威源仍是数据表里的 `skills[].text`）：

| 技能 | 修正后公开描述 |
| --- | --- |
| 不可挡突袭 | 锁定技，当你使用实体单体【杀】指定目标时，若你手牌中的【杀】牌数量大于该目标角色，你使用的此【杀】不可响应。你的【杀】牌数每超过该目标角色1张，伤害+100%。 |
| 守护后方 | 锁定技，当我方其他角色成为单体【杀】牌的目标时，若该角色没有此技能，将此【杀】牌的目标转移给你。 |
| 极速射线 | 锁定技，你使用的全体类实体牌不可被响应，且造成的伤害翻倍。 |
| 快速复生 | 锁定技，当你死亡后，下一个回合开始时若我方其他角色存活，你复活并恢复所有生命值。 |

### 两处差异已按新稿对齐（2026-11-25 第二轮）

- **守护后方**：文案写「单体【杀】牌」，实现改为 `CardUtils.isSingleKillCard`
  （含虚拟单体杀、转换杀；显式排除 `type: "skill"` 伤害载荷与 `_pendingDraw` 待摸牌），
  不再是 `isEntitySingleKill`。群体杀、我方目标、时停防爆队仍不转移。
- **快速复生**：文案只在「下一个回合开始时」判队友存活，实现把死亡瞬间的
  `teamAlive` 判定移除，`preventDeath` 只判时停/重复触发；`beginTurn` 保留判定。
  队友全灭时由 `shouldHoldRevival` 在胜负链兜底（全灭后待复活标记不再阻挡胜利），
  避免最后一只怪倒下后战斗被挂起一个回合。这不是复活条件的二次判定。

### 同批修复：目标转移后的出牌动画错位

`BattleEffectPlay.playCard` 在 `commit()`（即 `useCard`）**之前**就按
`pendingTargetUid` 画好飞行线，而【守护后方】在 `useCard` 最前才把目标改成防爆队：
线飞向原目标、`_playedTargetUid` 也记原目标，结算却打在防爆队，
`BattleAttackAnimations.reusedFlight` 对不上还会补第二条虚拟飞行。
现拆出无副作用的 `TenriInstituteSkills.plannedTarget`，动画层用它把 `targetUid`
预测成防爆队；`redirectTarget` 复用同一判定并负责写日志/台词。

## 三之二、AI 逻辑（2026-11-25 落地）

实现在 `src/original/tenri-institute-ai.js`，只从 `BattleAI.choose` 的
`characterMoves` 最前面接管，返回 `null` 即交回既有默认 AI，不改其它副本分支。

| 怪物 | AI 逻辑 | 实现要点 |
| --- | --- | --- |
| 机械警卫突击队 | 优先使用蓄力，随后集中使用【杀】牌攻击手牌数最少的敌方角色。 | `!actor.charge` 时先出【蓄力】只叠一层；目标按 `visibleHand` 升序取手牌最少者 |
| 机械警卫防爆队 | 正常使用卡牌，优先保留【闪】用于响应转移到自身的伤害。 | `aiMove` 返回 null 正常用牌；`aiHand` 剥掉【闪】/响应牌，避免主动打出或当费用 |
| 清理机器人 | 优先使用蓄力，随后优先使用【机枪扫杀】等全体攻击牌。 | 先蓄力；全体实体牌含无 `sweep` 的【魔王军入侵】，targetless 牌目标传自身 |
| 无垢食尸鬼 | 悍不畏死，优先使用高伤害的【杀】牌进行输出。 | 在 `tacticMove` 之前直接返回 `slashScore` 最高的【杀】，跳过治疗/防御/抽牌等保命战术 |

【蓄力】是基础牌堆里的战术牌（`charge: 1`，下一张【杀】伤害 ×2、可叠加），
所以「先蓄力再输出」对突击队与清理机器人都是有效增益；清理机器人的全体【杀】
（如【机枪扫杀】）同样吃 `chargeMultiplier`。防爆队转移过来的单体杀由
`battle-damage-resolution.js` 的自动响应链用【闪】抵消，保留【闪】即有效。

四个技能都判时停（米尔尤拉【神奇怀表】），内部标识用下划线字段，
`CardUtils.clean` 会剥除，复制 / 重放牌不会继承加成。

**已接入 1 首（研究所普通战斗）**：`publish/assets/new-bgm/tenri-institute-battle.c9d87b58.ogg`，
由素材包「研究所普通战斗_min.ogg」处理而来，1.66 MiB（低于场景音频 1.75 MiB 上限）。
`data-tenri-institute.js` 的 `mission.bgm` 指向它；4 只怪数据表没有各自 `bgm` 字段，
`GameBGM.battleTrack` 会回落到 mission 曲目。

处理链（`tools/check-tenri-bgm-seamless.js` 逐项复核）：
1. 解码后按原始 Ogg 末页 granule 裁掉 Vorbis end-padding 192 samples，消除回绕空白；
2. 首尾各 30ms 余弦淡化到 **零样本**，循环点两侧 `first=0 / last=0 / jump=0`；
3. 重编码到 88 kbps 以落进预算，写入 Vorbis comment `LOOPSTART=0` /
   `LOOPLENGTH=6658560`（采样单位）。

**2026-11-25 播放器已升级为 WebAudio 采样级无缝**（`bgm-webaudio.js` + `bgm-loop-metadata.js`）：
解析 Ogg Vorbis comment 的 `LOOPSTART/LOOPLENGTH`，按源采样率换算成秒，
设到 `AudioBufferSourceNode.loopStart/loopEnd`，回绕精确跳到循环点、跳过尾部 padding，
零样本闭合 + 无间隙。`bgm.js` 通过同构适配器接入，淡入淡出 / 时停挂起 / 切曲 / 音量全部保持。

**协议边界**：`available()` 只允许 `http:` / `https:` / `app:` 等 fetch 可用的协议启用 WebAudio；
`file://` 与 `blob://`（origin=null）下浏览器会以 CORS 直接拒绝 fetch/XHR 并在 console 打错误，
因此这些环境**静默回退** `HTMLAudioElement` + `loop=true`（配合已经做好的零样本闭合，听感仍连续、
零 console 错误）。Electron 目前用 `loadFile`（file: 协议），若后续注册 `app://` 自定义协议并改用
`loadURL`，无需改播放器即会自动切到采样级路径。

**音频波形检查结论**：素材包 5 首里 4 首首尾静音可柔和相接，但
「魔王军枪炮师杰明_min.ogg」尾部硬切（末 50ms RMS 441），直接 loop 会咔哒；
且 5 首合计约 10.16 MiB，现有长音频 17.74 MiB / 上限 21 MiB，全接会超预算。
因此另外 4 首角色曲暂不接入，压缩包本体仍完整保留在工作区。

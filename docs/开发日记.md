# 开发日记(Development Diary)

> 用途:流水记录每次更新——变更摘要 + 涉及文件路径。
> 规则(对后续所有会话):每次发生文件**新建/修改/删除**、代码改动、git 提交或影响项目本身的决策,必须在**本文件末尾追加一条记录**:
> 1. 日期小节(YYYY-MM-DD);
> 2. 变更摘要(做了什么、为什么);
> 3. **新建 / 修改 / 删除的文件路径清单**(相对仓库根的完整路径);
> 4. 提交 hash(如有)。
>
> **只记录与游戏项目相关的内容**;本机工具安装、系统环境改动等与项目无关的更新一律不写入本日记。
>
> 本文件只做时间线流水,**不做规则事实权威**;领域规范仍以 `docs/original/`、`docs/deepseek-rebuild/`、`docs/*.txt` 交接笔记为准。

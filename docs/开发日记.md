## 2026-09-08

### 1. 修复「废墟沙城与亚缇娜/玛利亚无法解锁」BUG

- **摘要**:
  - **现象**:通关兽人地下城·勇士级后,副本「废墟沙城」不开放,亚缇娜与玛利亚不加入角色栏,二者技能表现为"无效"。
  - **根因(三处叠加)**:
    1. `new-character-unlock-events.js` 中 `recordDungeonClear(state)` 只声明了 `state` 一个形参,但调用方 `dungeon-run-rewards.js:65` 传入的是 `(state, run)`;函数体内直接裸用 `run`,触发 `ReferenceError: run is not defined`,导致通关结算 `finish()` **整体中断**,其后第 78–79 行的废墟沙城解锁判定**永远执行不到**。此为主因。
    2. `unlock-event-progress.js` 的 `ids` 白名单未包含 `ruins_sand_city`,`complete()` 对未知 ID 直接 `throw`。
    3. `local-core-events.js` 的 `unlockEvent()` if-else 链缺少 `ruins_sand_city` 分支,走到兜底逻辑抛 `未知本地剧情解锁`;`checks` 表亦缺对应条目。
  - **修复**:补 `run` 形参;注册 `ruins_sand_city` 事件 ID 与 `durableEvidence`;实现解锁分支(置 `ruinsSandCityUnlocked` / `ruinsSandCityUnlockSeen`、清 `pending`、`unlock("artina")` 与 `unlock("maria")`)。
  - **纠正此前误判**:先前认为"难度误写为 `adventure`、应改为 `warrior`"**是错的**。`recordDungeonClear` 管辖的是**星野一家**(冒险级,`adventure` 正确);废墟沙城的**勇士级**判定位于 `orc-unlock-events.js:46` 的 `triggerRuinsSandCityUnlockEvent`,其原本即为 `warrior`,**正确无误**——只是因上述崩溃而无机会执行。本次**未改动任何难度判定**。
  - **验证**:在容器内加载真实模块做「修复前后」对照测试。修复前步骤 1 即 `ReferenceError` 中断;修复后四步全通(触发 pending → `unlockEvent` 成功 → 亚缇娜+玛利亚解锁 → `ruinsSandCityUnlocked` 为 true)。回归测试 4/4 通过(星野一家、兽人地下城、水下列车均无回归)。
- **修改**:`src/original/new-character-unlock-events.js`、`src/original/unlock-event-progress.js`、`src/original/local-core-events.js`
- **提交**:`4f8b4fe`(补 run 参数)、`8871708`(注册事件 ID)、`e1a77f9`(实现解锁分支);合并提交 `a430c6c`(分支 `fix/ruins-sand-city-unlock` → `魅魔杀`,临时分支已删除)

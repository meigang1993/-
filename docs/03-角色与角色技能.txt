===============================================================
  魅魔杀 - 正式角色与角色技能
  交接对象：DeepSeek 重制
  正式角色共 26 名
===============================================================

属性字段顺序：攻击 / 魔力 / 速度 / 最大生命 / 杀意上限 / 手牌上限 / 每回合摸牌(额外) / 初始摸牌(额外)
注意：drawPerTurn 和 initialDraw 是加在共享基础摸牌数 2 和共享初始摸牌数 4 之上的额外值。

【1. lokar - 罗卡尔】
定位：恋母勇者
战斗定位：输出
性别：男
基础属性：3 / 1 / 3 / 36 / 1 / 4 / 1 / 2
解锁：初始可用
成长曲线(maxHp:72, attack:13.5, magic:4.5, speed:10)

评价：持续进攻型物理核心。使用实体【杀】与【与我一战】可补充手牌和杀意，
热血契约提供回合内攻击成长，狂风绝息斩负责集中释放手中的全部【杀】。

技能：

1. 战斗之勇（被动）
   锁定技，当你使用一张实体【杀】或【与我一战】时，你从摸牌堆摸1张牌。
   若摸到【杀】或【与我一战】，你恢复1点杀意。

2. 热血契约（主动，出牌阶段限一次）
   你可以将1张手牌置入消耗牌堆，然后摸3张牌，并于本回合获得X点攻击力
   （X为你消耗牌堆中的牌数）。
   生成卡牌：战术牌，名为"热血契约"，效果同上。

3. 狂风绝息斩（限定技，出牌阶段）
   你依次使用手牌中的所有【杀】，并随机循环指定存活的敌方角色为目标；
   这些【杀】不消耗杀意。
   生成卡牌：战术牌，名为"狂风绝息斩"，效果同上。

【2. besta_doll - 贝丝妲魔偶】
定位：机器魔偶
战斗定位：输出
性别：女
基础属性：2 / 3 / 3 / 28 / 1 / 3 / 2 / 1
解锁：初始可用
成长曲线(maxHp:54, attack:7.5, magic:12, speed:7.5)

评价：红桃爆发与魔法收割核心。榨取精华以友方男性的生命值换取摸牌，
每张红桃令本回合魔力增加50%，并将物理攻击牌转换为魔法攻击；
追魂之刃会在实体【杀】被闪后重用原牌，锁魂镰刀负责群体连锁收割。

技能：

1. 追魂之刃（被动）
   锁定技，当你使用的实体【杀】被【闪】抵消后，你额外再次使用此牌1次。
   此次使用不消耗手牌和杀意，且不能再次触发此技能。

2. 锁魂镰刀（被动）
   锁定技，当你使用单体【杀】造成生命值伤害后，你对所有存活的敌方角色
   各造成等同于你魔力的无视护甲伤害。若有角色因此死亡，重复此效果，
   至多重复4次。

3. 榨取精华（主动，准备阶段限一次）
   你可以令一名友方男性角色失去X点生命值，然后你摸X张牌；
   每张红桃牌令你本回合魔力增加50%（按发动时的基础魔力加算，
   X为你手牌中的红桃牌数）。本回合内，你使用的所有物理攻击牌均转换为魔法攻击。
   生成卡牌：战术牌，名为"榨取精华"，效果同上。

【13. angelica - 安洁莉卡】

治疗；每回合可承受一名女性队友的魔法伤害，令其按自己的每回合摸牌数补牌。

技能：

1. 半魅魔血（触发）
   当你受到生命值伤害后，你摸2张牌，然后可以选择至多2张手牌并将这些牌
   交给一名其他友方角色。若星野依在队伍中且存活，星野依令你恢复
   等同于其魔力值的生命值。

2. 半魅魔精华（主动，出牌阶段限一次）
   你可以指定一名友方女性角色。该角色对你造成等同于其魔力值的魔法伤害，
   然后其摸X张牌（X为你当前每回合摸牌数）；指定星野依时不造成伤害。
   指定七位姐姐之一时，其对应儿子若在队伍中则获得1枚"绿帽"；
   指定娜娜莉或贝丝妲时，罗卡尔获得1枚"绿帽"。
   每名角色至多拥有5枚"绿帽"，每枚令手牌上限、杀意上限各+1，攻击力+30%。
   生成卡牌：战术牌，名为"半魅魔精华"。

===============================================================

【角色设计约束】

1. 角色技能是战斗规则，不要只做成展示文字。
2. 技能生成的虚拟牌必须标记来源，避免重复计数或错误触发。
3. 触发类技能必须支持中断、选择、取消、恢复和存档。
4. 角色关系效果只在正式数据中声明的对象上触发。
5. "绿帽"标记系统：每名角色至多5枚，每枚令手牌上限+1、杀意上限+1、攻击力+30%。
6. 双胞胎关系：芙萝娅和温蒂互为双胞胎，部分技能有联动效果。
7. 角色图鉴必须自动包含所有正式角色，不因数据文件位置而遗漏。
8. 解锁条件：部分角色初始可用（locked=true但无unlockCost），
   部分需要精华宝珠解锁，部分需要特定解锁标志。

# 03 卡牌与饰品

## 卡牌分类

- 基础攻击：`【杀】`、`【魔杀】`、`【狼牙杀】`、`【刺杀】`、`【机枪扫杀】`等。
- 响应牌：`【闪】`、`【看破】`。
- 战术牌：改变目标、牌堆、属性、状态或回合流程。
- 消耗牌：一次性资源，离开手牌后进入消耗牌堆。
- 状态牌：带有持续时间、判定、移除或抗性规则的特殊牌。
- 技能牌：角色技能生成的临时或虚拟牌，不应污染永久牌库。

## 牌堆

每一方拥有一套独立共享战斗牌堆。永久牌库中的每个实体卡会在战斗开始时克隆到己方战斗牌堆。牌可位于摸牌堆、弃牌堆、消耗牌堆、角色手牌或临时区域。

- 抽空时按规则洗回弃牌堆。
- 消耗牌进入消耗堆，不再回到普通抽牌堆。
- 跨阵营偷牌时，展示数量转移到持有者一侧；离手后回到原所属方的弃牌或消耗堆。
- 公共牌 trail 要区分实体牌、虚拟牌、来源牌、响应牌和转换牌。

## 牌面规则

- 牌名、花色、类型、效果说明是 HTML 文本叠加，卡牌插画只是视觉层。
- 【杀】默认消耗杀意；技能生成的“不消耗杀意”牌必须显式标记。
- 所有正式卡牌没有固定基础伤害；伤害读取牌声明的攻击力、魔力、护甲、成长值和倍率。
- 伤害触发应使用“若此牌造成生命值伤害”，不能把护甲伤害、闪避或被抵消误判为生命伤害。
- 攻击类别和伤害属性分开：物理攻击、魔法攻击是类别；物理、毒、雷、火、圣、暗、冰是属性。

## 关键正式牌

- `【杀】`：常规单体攻击，消耗杀意，可被【闪】响应。
- `【魔杀】`：魔法攻击类别，但当前可造成物理属性伤害。
- `【闪】`：响应【杀】。
- `【看破】`：响应战术牌。
- `【与我一战】`：目标先打出【杀（普攻）】，双方轮流使用；无法继续者承受最后出牌者按攻击力造成的物理伤害。
- `【狼牙杀】`：鲁卡专属无色牌，按回收规则反复回到手牌。
- `【刺杀】`：高压单体攻击，常由芙萝娅和相关技能虚拟生成。
- `【机枪扫杀】`：多段或多目标攻击，常由卡洛斯、杰洛特等技能生成。

## 卡牌描述标准

- 数值使用阿拉伯数字：`1张`、`2点`、`30%`。
- 目标写作“指定一名敌方角色为目标”“指定一名友方角色为目标”。
- 主动牌使用“使用此牌”；响应动作按规则区分“使用”和“打出”。
- 牌名用 `【牌名】`，标记用 `“标记名”`。
- 描述顺序：目标和主要效果 → 响应限制 → 后续触发 → 持续时间 → 操作提示。

## 饰品

饰品是永久装备系统。正式饰品共 30 个，由大厅饰品库存和图鉴统一管理。

- 每个角色最多两个装备槽。
- 点击空槽打开固定在该角色位置的选择器。
- 点击已装备槽立即卸下。
- 支持从库存拖拽到槽位，也支持拖回库存卸下。
- 熔炼必须先确认，且不能生成未知饰品。
- 饰品图鉴是全局最高层弹窗，四列名称网格与详情面板独立滚动。
- 记忆中的无效选择必须回退到第一个正式饰品。

## 卡牌收藏显示

- `实体卡总数`统计永久实体数量，包括重复牌。
- 图鉴进度统计唯一正式牌名。
- 公共牌库分组显示 `持有×N`。
- 战斗牌堆总数必须包含摸牌堆、弃牌堆、消耗堆及同侧所有手牌，并显示手牌包含数。

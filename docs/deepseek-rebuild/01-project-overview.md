# 01 项目总览

## 产品定位

《魅魔杀》是桌面优先的哥特风卡牌战斗与据点经营游戏。玩家在殿堂管理资源、收集角色和卡牌，组建 1 至 4 人队伍，选择副本和难度，在共享牌堆战斗中通过出牌、响应、角色技能和饰品组合击败敌人。

视觉基线为 `1280x720` 横屏。游戏应像一个可反复操作的桌面游戏工具，而不是营销页面。

## 核心循环

1. 在殿堂查看资源、任务、牌库和饰品。
2. 在客厅查看角色等级、技能、立绘和装备。
3. 选择队伍、正式副本和难度。
4. 进入地图，处理节点、事件和战斗。
5. 战斗中管理手牌、杀意、生命值、护甲、状态和技能时机。
6. 胜利后结算金币、精华宝珠、卡牌、饰品、经验和解锁进度。
7. 回到殿堂强化收藏，再挑战更高难度。

## 主要资源

- `莉莉丝元`：商店购买卡牌和部分解锁。
- `精华宝珠`：角色或内容解锁使用。
- `饰品`：永久收集并装备，每个角色最多两个槽位。
- 卡牌实体：永久进入公共牌库；重复卡牌必须保留实体数量。
- 角色经验：副本战斗结算获得，等级范围为 0 至 15。

## 角色基础属性

- 生命值 / 最大生命值
- 攻击力：物理攻击和部分固定技能的主要数值。
- 魔力：魔法攻击、治疗和部分技能的主要数值。
- 速度：决定准备顺序和部分技能效果。
- 杀意：角色使用【杀】类牌的回合资源。
- 手牌上限
- 每回合摸牌数
- 初始摸牌数

所有角色有一个五类战斗定位标签体系。定位用于展示和 AI 参考，不应替代具体技能规则。

## 难度

正式难度使用递增的敌人强度和经验倍率。经验倍率为 `1 / 1.15 / 1.35 / 1.6 / 1.9`。敌方生命值向上取整，攻击力和魔力四舍五入，速度四舍五入。

## 等级

等级为 0 至 15。下一等级经验需求依次为：

`100, 160, 240, 340, 470, 620, 800, 1020, 1280, 1580, 1920, 2300, 2720, 3180, 3680`

从 0 级到 15 级总计 `20410` 经验。每个角色的四项成长曲线独立，等级自动提升最大生命值、攻击力、魔力和速度，不存在手动加点。

## 正式范围

包含已完成的 26 名角色、正式卡牌、正式饰品、正式怪物、已完成副本、殿堂/客厅/熔炉/战斗/胜利结算和存档系统。

不包含：新副本、亚缇娜、玛利亚，以及任何仅存在于草稿或测试阶段的内容。

# 05 战斗规则

## 战斗结构

1. 战斗初始化：复制双方永久牌库，建立摸牌堆和弃牌堆。
2. 初始摸牌：共享基础初始摸牌为 4，角色 `initialDraw` 是额外值。
3. 回合开始：按速度和当前状态选择角色，执行准备阶段。
4. 判定阶段。
5. 摸牌阶段：共享基础摸牌为 2，角色 `drawPerTurn` 是额外值。
6. 出牌阶段：使用攻击牌、战术牌、技能牌和响应。
7. 弃牌阶段：处理手牌上限、分享和状态。
8. 结束阶段：结算结束技能、持续状态、翻面和回合标记。
9. 敌方回合由 AI 自动行动，测试单位可停留在输入阶段。

## 目标和响应

- 目标选择必须只显示合法目标。
- 玩家手牌区在特殊提示期间可切换为技能拥有者的手牌。
- 需要展示目标手牌的规则使用中央手牌查看层；普通队友选择使用底部手牌区。
- 所有手牌和目标选择都必须支持取消、非法牌禁用和 stale 输入拒绝。
- 【闪】响应【杀】，【看破】响应战术牌。
- 响应、反击、转移、代承伤、借牌和多段攻击都可能中断当前动作，必须保存 continuation。

## 杀意

- 普通【杀】类牌通常消耗杀意。
- 不消耗杀意的虚拟牌或临时牌必须显式标记。
- 杀意上限、恢复、清零和翻面状态由角色技能或战斗规则控制。
- 不能因虚拟牌、响应牌或内部镜像重复扣杀意。

## 伤害

伤害结算顺序：

1. 创建带来源、目标、属性、攻击类别和牌身份的伤害事件。
2. 处理闪避、护甲、转移、代承伤、反击和响应。
3. 应用护甲吸收。
4. 应用实际生命值伤害。
5. 触发毒、火、雷、圣、暗、冰等属性效果。
6. 记录贡献、击杀和后续技能。
7. 继续被中断的多段攻击或回合流程。

攻击类别与属性独立。魔法攻击可以造成物理属性伤害；只要没有实际扣除生命值，就不能触发“造成生命值伤害后”。

## 状态牌

状态牌要有唯一身份、创建来源、持续时间、移除条件、判定和 Elite/Boss 抗性。状态牌离开手牌时按统一规则进入消耗堆或指定区域，不得出现重复实例。

毒与燃烧伤害要记录施加者。毒使用最新施加者作为来源；燃烧牌保留自身来源，即使牌更换区域或持有者。

## AI

一般敌方单体目标评分包含：

- 低生命值
- 空手牌
- 价值牌
- 可攻击性
- 魔法适配
- 当前生命值

实际选择不是永远锁定最高分：40% 概率选择最高分，60% 概率在所有存活目标中均匀选择，最高分目标也参与均匀池。规划预览使用确定性的最高分，不消耗随机数。

明确的花色标记、圣痕、破甲、固定目标和技能专属目标规则优先于一般 AI。

## 多段和中断

- 多段攻击每一段都必须拥有独立 continuation。
- 处理中断时先推进步骤游标，恢复时只执行未完成步骤。
- 不得重复扣费用、重复应用伤害、重复发牌或重复触发技能。
- 退出战斗必须使旧输入和旧异步结果失效。

## MVP

战斗胜利显示贡献最高的 MVP，但 MVP 只影响展示：

`damage + healing * 0.85 + kills * 10 + responses * 2 + cards * 0.5`

结果四舍五入。过量伤害按目标受击前生命值封顶；毒/燃烧击杀归属状态来源；虚拟内部牌不重复计算用牌数。

## 结算

- 胜利：确认战斗、经验、金币、掉落和待处理动作。
- 失败：只清理当前 run 的可丢弃奖励，保留不相关奖励。
- 结算必须有幂等 receipt。
- 结算失败显示错误和重试，不得报告假成功。
- 新副本不能在旧的待处理结算队列未清空前启动。

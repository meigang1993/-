# 06 UI、交互与视觉

## 总体风格

- 哥特风、近黑背景、深红命令区、古金边框。
- 角色和怪物立绘是主要身份信号。
- 战场使用浅色实体卡面，与深色场景形成对比。
- 不使用营销式 Hero、说明卡片堆叠或单一紫色渐变。
- 标准卡片和按钮圆角 `4px-8px`；大型叙事弹窗可更圆。

核心色：

- 深黑：`#08070a`、`#17131a`
- 哥特红：`#a8193f`
- 骨白文字：`#e8dcc8`
- 古金：`#c9a764`
- 亮粉选择、紫色魔法、蓝色响应、橙色火焰、绿色成功、红色危险。

## 页面

### 标题页

中央八边形女主立绘、标题 `魅魔杀`、按钮 `新游戏`、`读档`、`设置`，右下角 `制作人员`。标题页不显示大厅导航。

### 殿堂

顶部栏显示标题、副标题、莉莉丝元、精华宝珠、饰品、版本和设置。中央展示据点和当前目标。右上角有 `更新公告`。底部导航为 `殿堂`、`客厅`、`熔炉`。

殿堂侧栏入口包括：饰品、商店、牌库、悬赏、存档和出征。

### 客厅

展示已解锁角色。角色卡显示立绘、等级、经验、战斗定位和核心属性。详情面板包括属性、技能、两格饰品、皮肤和立绘放大。

### 熔炉

处理饰品熔炼、资源转换和容量压力。破坏性操作必须确认。

### 出征设置

显示当前队伍、角色列表、正式副本、难度和最终出征按钮。队伍人数为 1 至 4。按钮状态应区分锁定、请选择队伍、确认出征和出征中。

### 战斗

战斗隐藏大厅顶部栏和底部导航，最大化战场。

- 上方：回合、资源和状态。
- 中央：己方和敌方角色、生命、护甲、状态、目标高亮。
- 下方：当前手牌、杀意、技能和操作提示。
- 侧边或可开面板：公共出牌轨迹、战斗日志。
- 当前行动者使用红金高亮；合法目标使用稳定轮廓。

### 胜利与失败

显示结算结果、MVP、经验、奖励、待处理状态和返回殿堂按钮。动画不能成为结算成功的唯一条件。

## 弹窗层级

Escape 关闭顺序：

1. 立绘放大
2. 确认/公告
3. 存档槽
4. 角色详情
5. 大厅模态框
6. 战斗日志
7. 设置
8. 制作人员

最高层弹窗获得输入，底层界面必须 inert，而不是只变暗。

## 布局和移动

- 只做横屏优先，不做独立竖屏分支。
- 使用 `100vh` 兜底和 `100dvh` 主规则。
- `html/body` 不滚动，长内容在所属面板内部滚动。
- flex 滚动子项必须设置 `min-height: 0`。
- 使用 safe-area padding。
- 监听 resize；不要缓存初始化时的宽高。
- 按钮和可点击区域至少 44×44px。
- 使用 Pointer Events；不要把鼠标和触摸事件重复绑定。

## 媒体和动画

- 媒体 `src` 只能绑定真实相对资源、可信 HTTP URL、data URL 或 blob URL。
- 文本内容不能先绑定到 `<img src>` 再用 CSS 隐藏。
- 同一对象 rerender 时保留已有媒体 DOM 和动画进度。
- 卡牌移动显示完整牌面；隐藏信息使用牌背。
- 音效区分飞牌、伤害、掉血、治疗、护甲和胜利。

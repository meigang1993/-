===============================================================
  魅魔杀 - UI描述与界面说明
  交接对象：DeepSeek 重制
===============================================================

【一、总体风格】

哥特风、近黑背景、深红命令区、古金边框。
角色和怪物立绘是主要身份信号。
战场使用浅色实体卡面，与深色场景形成对比。
不使用营销式Hero、说明卡片堆叠或单一紫色渐变。
标准卡片和按钮圆角 4px-8px；大型叙事弹窗可更圆（18-32px）。

核心色板：
- 深黑背景：#08070a、#17131a、#260913
- 哥特红（活动控件、命令强调、战斗焦点）：#a8193f
- 骨白文字（正常前景）：#e8dcc8
- 古金（边框、标题、选中轮廓）：#c9a764
- 亮粉选择：约#ff5cab
- 暖金高光：约#ffd88d
- 紫色魔法、蓝色响应、橙色火焰/消耗、绿色成功、红色危险

不要把整体UI变成单一紫、蓝、米或红色系。金色、深红、紫色、中性黑和
语义战斗色必须保持视觉区分。

字体：系统UI字体栈
-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
字间距为0。标题类型保留给"魅魔杀"和主要场景名。
长名称使用省略号而不是调整周围控件大小。

【二、屏幕家族（24种）】

1. 标题页（Title Screen）
   - 中央八边形女主立绘（besta-villa-new.webp）
   - 标题"魅魔杀"在下半部暗化图像上
   - 主按钮：新游戏、读档、设置
   - 制作人员在右下角
   - 标题页不显示顶部栏和底部导航
   - 存储启动失败时替换为可读错误和重试按钮

2. 标题设置（Title Settings）
   - 窄居中设置面板覆盖模糊标题
   - 存档/读档/全屏、撤退、两个音量滑块
   - 1x/1.5x/2x 分段速度选择
   - 手动响应复选框
   - 返回命令
   - 不可用撤退可见地禁用

3. 制作人员（Credits）
   - 粉色羊皮纸风格居中面板
   - 角落装饰
   - 关闭按钮、背景点击关闭、Escape关闭
   - 内容鸣谢开发、AI辅助、音乐来源和生成角色美术

4. 殿堂（Villa Hall）
   - 固定顶部资源栏
   - 左侧操作栏
   - 全屏女主背景
   - 目标和主要出征命令
   - 底部导航：殿堂、客厅、熔炉
   - 侧栏入口：饰品、商店、牌库、悬赏、存档、出征
   - 更新公告在右上角
   - 活动模态框使殿堂inert

5. 更新公告（Update Notice）
   - 大型暗色可滚动模态框
   - 日期、分段和项目符号列表
   - 内部垂直滚动
   - 明确关闭和背景关闭
   - 殿堂保持可见但模糊和阻止

6. 出征设置（Expedition Setup）
   - 居中准备模态框
   - 当前队伍条
   - 队伍/测试命令
   - 副本区块
   - 难度卡片
   - 队伍人数1-4
   - 难度显示锁定/推荐状态
   - 最终命令在锁定/选择队伍/确认/忙碌间切换

7. 队伍名册（Party Roster）
   - 可滚动的角色卡
   - 立绘、定位、皮肤操作和选中轮廓
   - 点击切换队伍成员
   - 满队阻止未选中卡
   - 至少保留一名成员
   - 返回回到出征

8. 商店（Shop）
   - 六库存卡牌网格
   - 资源/容量标签
   - 卡牌文本、价格
   - 删除服务区域
   - 售出槽位保持可见
   - 不足货币/容量禁用购买
   - 购买和删除使用异步守卫状态和可见重试

9. 牌库（Deck）
   - 四列密集卡牌收藏
   - 类型过滤器
   - 花色库存
   - 计数
   - 图鉴命令
   - 过滤器不改变存储的牌库
   - 分组牌保留物理花色计数
   - 内部模态滚动保留周围壳

10. 卡牌图鉴（Card Codex）
    - 顶层独立卡牌图鉴对话框
    - 收藏计数器
    - 可滚动卡牌网格
    - 详情面板
    - 从牌库打开
    - 牌库在下方inert
    - Escape/右键/背景/关闭只关闭图鉴

11. 饰品库存（Relic Inventory）
    - 两列队伍装备布局
    - 库存摘要
    - 图鉴命令
    - 每个角色两个直接操作槽位
    - 选择器固定在打开的角色位置
    - 保留模态滚动位置

12. 饰品图鉴（Relic Codex）
    - 顶层紫色饰品图鉴对话框
    - 四列名称网格
    - 固定详情面板
    - 仅从大厅饰品库存打开
    - 客厅角色详情饰品标签只有装备控制
    - 网格和详情独立滚动
    - 已拥有条目发光，未知条目灰色
    - 焦点陷阱和恢复
    - Escape/背景/关闭只关闭图鉴

13. 悬赏板（Bounty Board）
    - 左侧大任务列表
    - 右侧粘性已接任务摘要
    - 可接、已接、已完成、阻止和自动结算状态保持区分
    - 任务操作守卫且可重试

14. 存档槽（Save Slots）
    - 居中存档管理器
    - 模糊游戏场景
    - 自动存档摘要
    - 三个手动槽位
    - 加载/错误/空状态明确
    - 槽位激活打开确认
    - 处理阻止面板
    - 部分同步暴露修复/重试

15. 孵化室（Nursery）
    - 全内容页
    - 标题条
    - 水平角色美术画廊
    - 角色卡以图片为主
    - 返回和角色图鉴命令在标题中
    - 长画廊在页面内滚动

16. 角色图鉴（Character Codex）
    - 紫色图鉴页
    - 标题摘要
    - 角色网格
    - 右侧跳转栏
    - 居中技能详情
    - 锁定角色使用去色/剪影处理
    - 悬停或点击显示定位/技能详情
    - 选中详情不遮挡全局导航

17. 客厅/训练（Training/Living Room）
    - 全页"别墅客厅"
    - 说明性标题
    - 已解锁角色成长卡
    - 卡片显示等级、当前经验和四项成长核心属性
    - 打开角色显示0级/当前/15级数值
    - 保留页面滚动
    - 完整位置描述在属性标签
    - 技能标签省略
    - 没有升级、加点、重置或推荐控件

18. 饰品熔炉（Relic Furnace）
    - 全页
    - 标题、库存计数、返回命令
    - 饰品分解列表或空消息
    - 已装备饰品被排除
    - 破坏性分解使用确认和可见奖励结果
    - 空库存保持可读

19. 副本地图（Dungeon Map）
    - 全宽自下而上路线图
    - 顶部统计、撤退、背包
    - 节点、连接线和层标签
    - 已完成/当前/可选/锁定节点视觉区分
    - 只有合法的下一层节点可点击
    - 待结算禁用地图

20. 测试战斗设置（Test Battle Setup）
    - 居中设置模态框
    - 难度选项卡
    - 平行友方/敌方选择器
    - 每方1-4
    - 锁定友方仍标记
    - 难度只影响测试敌人
    - 卡牌、皮肤和饰品使用专用嵌套控件

21. 战斗（Battle）
    - 六带战场：敌人、敌方牌堆、公共轨迹、己方牌堆、友方、手牌/操作区
    - 隐藏大厅顶部栏和底部导航
    - 卡牌、技能、目标、阶段命令、撤退、日志、设置和水平手牌滚动同时可读

22. 战斗角色信息（Battle Character Info）
    - 大型三列详情覆盖层
    - 垂直标签：属性、技能、饰品、皮肤、特殊立绘
    - 全立绘
    - 点击战场或活跃立绘打开
    - 背景战斗inert
    - 立绘支持放大
    - 关闭恢复战斗焦点和滚动

23. 战斗设置（Battle Settings）
    - 同标题设置面板
    - 覆盖模糊战斗
    - 战斗保持暂停/阻止
    - 存档/读档和偏好可用
    - 撤退仅在当前战斗状态允许时启用

24. 胜利结算（Victory Settlement）
    - 居中紫金结算面板
    - 胜利摘要
    - MVP条
    - 队伍排名
    - 指标
    - 继续命令
    - 条目在结算展示就绪前保持锁定
    - 点击就绪面板或明确命令只继续一次

【三、战斗界面详细布局】

战场分为六个水平带：
1. 敌方角色行（顶部）
2. 敌方牌堆摘要
3. 中央公共区（回合数和翻面行动历史）
4. 己方牌堆摘要
5. 友方角色行
6. 手牌/操作区（底部，含活跃立绘）

每个单位显示：立绘、名称、手牌数、行动数、HP、护甲、防御和状态徽章。
活跃单位使用深红/金色发光；可选目标使用白色提升和轮廓；
敌方思考使用静态紫色发光和标签。

牌堆摘要显示：摸牌堆、弃牌堆、消耗堆、总数、手牌数、洗牌数。

手牌区拥有：实际手牌、阶段提示、主要操作命令、技能列和活跃角色立绘。

卡牌面：104x160，包含花色、名称、插画、类型、效果摘要、转换/来源标签
和伤害预览。插画是资源层，花色/名称/类型/效果/伤害是HTML文本。

选择与目标：
- 点击可出牌选中并提升约18px，带粉色和紫色发光
- 再次点击取消选择
- 禁用牌保持可见但去色，不能提升
- 可目标单位悬停预览，选中目标保留白色轮廓
- 确认目标牌显示目标线并同时开始卡牌飞行
- 友方行动线白色，敌方行动线红色
- 多目标攻击对每个存活目标画一条线

战斗覆盖层：
- 战斗日志：右侧半透明抽屉，编号条目，内部滚动
- 设置：居中阻止面板覆盖模糊战斗
- 角色信息：大型立绘主导覆盖层
- 技能说明：接近屏幕中心，友方紫色光，敌方红色，饰品暖金色
- 伤害、HP损失、治疗、护甲、元素属性和魔法效果使用独立视觉和音频层
- 缺失立绘或卡牌图渲染标记fallback和持续"重试素材"操作

【四、弹窗层级与关闭】

Escape 关闭顺序（从高到低）：
1. 立绘放大
2. 确认/公告对话框
3. 存档槽确认或存档面板
4. 角色详情
5. 大厅模态框
6. 战斗日志
7. 设置
8. 制作人员

最高可见阻止层获得输入。低层标记inert，不只是变暗。

每个阻止面板有可见的关闭/取消/返回/确认路径。
更新和悬赏大厅模态框可点击背景关闭。
密集管理模态框使用明确关闭按钮避免意外关闭。
战斗日志通过关闭按钮、右键或Escape关闭。

【五、殿堂管理交互细节】

- 殿堂左侧栏命令是操作性的，不是装饰性卡片
- 每个命令结合名词和简短用途行
- 首次出征目标是背景美术上的边框条
- 主要出征按钮是最强的殿堂命令
- 殿堂背景美术保持可检查
- 暗色覆盖保护文字但不隐藏女主的脸、服装、王座、翅膀或姿势
- 商店卡牌在同一卡中显示花色、名称、类型、完整效果文本和价格
- 售出库存从不禁默消失
- 牌库视图按身份分组同时显示实际花色组成和拥有计数
- 图鉴视图区分发现和拥有
- 悬赏详情在任务列表滚动时保持粘性
- 客厅和孵化室是页面目标，不是大厅hero内的嵌套卡片
- 存档UI报告自动存档元数据、队伍摘要、资源、同步状态和关键里程碑行为

【六、饰品操作交互】

- 点击空槽打开该确切槽位的选择器
- 点击已装备槽立即卸下
- 从库存拖拽饰品到槽位装备
- 从已装备拖回库存卸下
- 选择器固定在打开的角色位置，列表滚动时保持位置
- 打开另一个角色保留被点击角色的模态位置

【七、异步与失败反馈】

- 提交的异步控制变为锁定并显示任务特定忙碌标签（出征中...、保存中...等）
- 同一动作的重复激活被拒绝，不相关控件保持可用
- 加载、空、错误和重试状态视觉区分
- 失败的保存/设置/结算/战斗素材工作留下持续警告和明确重试命令
- 未捕获运行时异常打开顶层阻止错误对话框，报告稳定错误代码，
  提供"返回重试"，恢复后焦点恢复到先前控件
- 破坏性或状态替换操作使用确认覆盖层
- 成功反映在变更的屏幕状态和状态/日志文本中
